# Research contributions

Reproductions, counterexamples, clearer explanations and bounded experiments are welcome. Please open an issue describing the declared premises, the expected result and the actual result. Include the stage, parameters and software version. Do not post private manuscripts, credentials or identifying research-participant information.

For a code change, use a branch and open a pull request. State what changed, which mathematical contract applies, and how you checked it. Keep experiment results separate from claims about general alignment or operational safety. Respect LICENSE.txt; a contribution must not introduce incompatible material.

Run `npm test` and `npm run test:python` where the relevant runtimes are available. The six downloadable scripts use Python 3.10+ and the standard library. See MODULE-CONTRACT.md before adding an experiment.
