# Public edition contents

This edition includes all seven experiment engines and controls, plain-English and mathematical definitions, precise manuscript citations, author-supplied publication links, numerical reports, standalone Python downloads, implementation sources, tests and software terms.

It excludes every source manuscript PDF, the unpublished book rendition, source Word documents, correspondence, previous private archives and credentials. The original Orchard logo is included only to identify the author’s laboratory and remains excluded from the software licence.

The public licensing page presents the permissions guide and full software terms.

Version 0.7 also includes the author-approved Orchard vision page, a seventh independent Python script, and the updated 49-entry evidence map.
